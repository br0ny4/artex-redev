## 版本

- 规范 §9.1 要求 Agent 首个响应以 `[RULES_LOADED v2.5]` 开头，并声明"版本与文件头一致"；
- 但**当前文件头没有版本号行**（疑似转换时丢失或原文未写）。本仓库按 §9.1 记载的 `v2.5` 处理，并在 `policy.yaml:spec.version` 中固定为 `"2.5"`；
- 建议：请规范维护方在文件头补 `version: 2.5`，之后由平台在启动时校验 `policy.yaml:spec.version` 与文件头一致，不一致直接拒绝启动在线域。

## 改动纪律

- 本文件是**依据**，不是可自由裁剪的配置。任何偏离规范的行为都必须在 `policy.yaml` 中以显式条目出现，并附变更说明与审批记录（规范第九章 4：版本变更后以新版为准；已开始的测试按开始时的版本执行）。
- 规范未列举的情形：按"最小影响 + 从严解释"处理（规范开篇"解释原则"）。
